# EA development data v1 provenance

Status: generated and frozen as a development namespace. It contains prompts
only, with no model outcomes, labels from HERALD, predictor fit, or confirmation
population.

## Generation

- Namespace: `ruler-ea-dev-v1`, generated by `scripts/prepare_ea_development.py`.
- Official NVIDIA/RULER checkout: commit
  `c3f5e3b4f87f97e048793bb510a3a6b19a46bf3a`.
- Tasks and seeds: 12 `niah_single_2` rows at `2026090603`, and 8 `cwe` rows at
  `2026090604`.
- Official sizing: `max_seq_length=4096`; downstream caps are 128 NIAH and 120
  CWE tokens. The native Qwen transform is
  `apply_chat_template(user, tokenize=True, add_generation_prompt=True)`.
- The bounded public Paul Graham corpus is reused as an input source, with hash
  `807e9e9a259efb99cd1cc13018c254e5fb74ea714c827b9c0d5c1706a2e49571`; its URL
  list hash is `a1f156bd460fe6c0c4fc063deb3ed79cff1a17a26cc5b061fac3f05e14f68db3`.
  The old v1 manifest and raw files were not modified.

The manifest records raw Qwen token counts, rendered Qwen chat-template counts,
prompt token hashes, official raw-record metadata, generator source hashes, and
tokenizer file hashes. Recomputed counts matched every row: Qwen chat tokens
range from 3369 to 3982 for NIAH and 3712 to 3941 for CWE.

## Folds and uniqueness

Four folds were assigned before any outcomes, by sorting NIAH on official
`token_position_answer` and CWE on official raw length, then round-robin assigning
within each task. Each fold has 3 NIAH and 2 CWE prompt groups. The task label is
for fold balance only and is not a downstream feature. Every arm for a prompt must
remain in its prompt group.

The canonical `(task, prompt, answers)` hashes have zero overlap with the old
12-row `ruler-pilot-v1` manifest, whose unchanged manifest hash is
`05db8d34df8022d99c200164990cfb28d41cbb20dfd5e8238aa42641eec40f54`.

Reproduce with:

```text
.venv-v4/bin/python scripts/prepare_ea_development.py
```

This step performs CPU tokenization and official prompt generation only. No GPU
job or outcome collection is part of this provenance record.
